# Plan Command

Use this command when the task needs a deliberate plan before implementation.

What to do:
1. Restate the user request in precise terms.
2. Surface assumptions, risks, and unknowns.
3. Break the work into phases with concrete file-level steps.
4. Include a verification strategy.
5. Wait for confirmation before implementation if the task is large or risky.

Use for:
- new features
- major refactors
- cross-cutting configuration work
- migrations and rollout planning
