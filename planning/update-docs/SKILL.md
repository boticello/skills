# Update Documentation

Synchronize documentation with the real source of truth.

Workflow:
1. Identify which files or commands define reality.
2. Update reference sections from those sources.
3. Preserve curated prose where possible.
4. Flag stale or manual-only sections separately.

Typical sources:
- package scripts
- environment templates
- route or API definitions
- deployment config
- repository structure
