# Session Wrap

Use this when ending a work session to create a durable handoff.

Structure the reflection with:

## Done
What was accomplished this session.

## Decisions
Key decisions made, with references when possible.

## Next
What to pick up next, in priority order.

## Open
Unresolved questions, blockers, or decisions needing input.
