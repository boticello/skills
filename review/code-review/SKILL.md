# Code Review

Review current changes with a findings-first mindset.

Check for:
- bugs and regressions
- security risks
- missing validation or error handling
- missing tests
- maintainability traps

Output expectations:
- findings ordered by severity
- file references where possible
- brief summary only after findings

Skip low-value stylistic commentary unless it clearly violates local conventions.
